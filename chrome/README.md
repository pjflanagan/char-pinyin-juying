
# Chinese New Tab Chrome Extension

Loads a random character from the lessons a user has learned and displays it in the newtab screen in Chrome.

[Install From Chrome Web Store](https://chrome.google.com/webstore/category/extensions)

![Screenshot](https://github.com/pjflanagan/chinese-words-chrome-extension/raw/master/assets/screenshot-2.png "Screenshot")

## Sources

- Chinese lessons from [Duolingo API](https://api.duolingo.com)
- Definitions, and pinyin from [Pepebecker Github](https://github.com/pepebecker)
