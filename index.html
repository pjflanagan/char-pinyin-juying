Study Resources

  • Flashcards - Sets I've found online that I've turned to flashcards. (Curated sets coming soon)
  • 讀 Tool - Type or copy/paste text to see pinyin and zhuyin, reformats to traditional.
  • 注音 Trainer - Randomly pick a character and display only the zhuyin to practice reading.
  • 唱歌 - A collection of popular karaoke songs in mandarin with pinyin/english subtitles.

About me

Hi, I'm Peter and I've been studying mandarin for a few years now. Every now and again I find it helpful to build a little web tool to help me practice something. These tools are free for anyone to use.

* Many of these tools were built by a student, not a native speaker. There may be errors. Characters often default to the most common pronunciation which may not be correct in all contexts.
