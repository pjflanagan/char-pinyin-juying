Study Mandarin

Hi, I'm Peter and I've been studying mandarin for a few years now. Every now and again I find it helpful to build a little web tool to help me practice something. These tools are free for anyone to use.

* Keep in mind, these were built by a student, not a native speaker. There may be errors.

  • Reading Tool - Copy and paste text you find to see pinyin and zhuyin, reformats to traditional.
  • Zhuyin Flashcards - Coming soon, randomly pick a character and display only the zhuyin to practice reading.
